# Release checklist

- [x] Public repository created and readable.
- [x] Raw/patient-level data excluded.
- [x] Third-party image binaries excluded; source/provenance documented.
- [x] Public-tree audit script present.
- [x] GitHub Actions safety/syntax workflow present.
- [x] Citation metadata present without a false DOI or unreleased version.
- [x] Scientific claim boundary documented.
- [x] Materialized analysis code/results/provenance reviewed for public release.
- [ ] Explicit software license selected by the code owner after upstream-license review.
- [ ] Final manuscript-to-code consistency check performed immediately before submission.
- [ ] Immutable Git tag and GitHub Release created.
- [ ] Release archived with a preservation DOI.
- [ ] DOI inserted into `CITATION.cff`, `README.md`, and manuscript code-availability statement.

Do not check an archival item until the corresponding external action has actually completed.
