# Scientific claims boundary

The released evidence is pseudo-prospective, not a genuinely future-unseen evaluation. The simple median count ensemble is retained because the strongest new point challenger did not show a paired credible improvement. Recent burden remains the operational ranker. Optional sources were retained only when origin-safe and beneficial; none of the five new screened groups met that standard. Colab results are not evidence until Mac import and rescoring. No causal, clinical-deployment, or national-policy effectiveness claim is supported.
